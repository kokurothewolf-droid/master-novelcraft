# Behavioral acceptance tests (manual, not yet run)

Run these with the installed skill and grade **pass / partial / fail** with supporting excerpts. Static integrity checks do not validate prose quality or agent behavior.

|---|---|---|

## Conflict-specific failure signals

Any instruction that mandates a fixed theme, complete beat-sheet, required protagonist conversion, perpetual cliffhanger, no exposition, a laugh/page target, or Japanese script headings **without explicit author approval** fails. Any instruction treating opera techniques as required content for this novel/light-novel package fails. Any claim that source skill missing sibling material was read fails.
