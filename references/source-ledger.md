# Source ledger and adaptation status

Read this before making a source attribution. The package contains **original contributed skill text**, much of it Chinese-language material. The active English references are **selective syntheses and novel adaptations**, not certified full translations. Attribution to named authors or books is attribution *as asserted by the supplied documents*, unless independently checked later.

## Classification labels for educational or source-driven responses

- **[Moore-attributed]**: from the supplied transcript as attributed to Alan Moore.
- **[Secondary interpretation]**: article author's commentary about Moore.
- **[SW-source]**: a contributed craft system or example, with exact folder/section.
- **[Novel adaptation]**: our translation of techniques into prose-specific actions.
- **[Author preference]**: confirmed user selection or project canon.
- **[New synthesis]**: implementation idea not claimed as a sourced quotation.

Source location convention: `sources/sw/sw-<name>/source-skill.md §<heading>` or an archived `reference.md`. Literal examples and case study numbers are preserved only as source case evidence. Chinese-language source excerpts can be located using their original section headings in the archived files.
